Рабочая папка - папка на компьютере, в которой человек работает на проектом
Индекс - зафиксированные для коммита изминения в проекте
Коммит - сохранение "снимка" текущего состояния проекта
Git - система контроля версий
Github - сайт для хостинга репозиториев Git
git status - показывает состояние репозитория
git diff - сравнивает состояние рабоей папки и последнего коммита
git diff --staged - сравнивает состояние индекса и последнего коммита
